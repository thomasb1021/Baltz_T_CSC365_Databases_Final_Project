This repository contains a final project completed for 
CSC-365: Introduction to Databases.

We completed this project while studying abroad in Barcelona in the Spring 
of 2025, which inspired us to choose a dataset related to both the local 
culture and a shared interest of ours: fútbol.

The project was developed in Jupyter Notebook using Python and SQLite. 
We used a publicly available [dataset](https://www.kaggle.com/datasets/hugomathien/soccer) 
from Kaggle  to create tables and indexes, perform database queries, and 
generate several visualizations from the derived data.

The notebook also includes interactive visualizations built with `ipywidgets`
(e.g., dropdown-driven player analysis views). These components are intended
to be run locally in Jupyter Notebook or VS Code; GitHub's notebook preview
may not fully support interactive widget rendering.

This repository is being shared for portfolio and archival purposes. The code 
is not actively maintained, and some components may require updates to run in 
a modern environment.
